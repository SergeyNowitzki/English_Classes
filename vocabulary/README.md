# Vocabulary

Word lists, collocations, and topic banks **without** a full lesson wrapper.

Suggested split when the folder grows:

```
vocabulary/
  topics/
    money-and-work/     ← pairs well with the FIRE lesson
    travel/
    health/
    environment/
  word-building/        prefixes, suffixes, noun/verb/adjective families
  phrasal-verbs/
```

A complete class that *uses* the words still goes in `lessons/`.
