# Pupil folders

Each pupil works on a separate branch named `pupil/<name>` and sends homework
only to their matching folder.

```
pupils/
  anna-k/
    2026-09-26-fire-writing/
      answer.md
```

The folder name under your name must match the assignment folder in `homework/assignments/`.

Example:

- branch: `pupil/anna-k`
- answer: `homework/pupils/anna-k/2026-09-26-fire-writing/answer.md`
- submission: pull request from `pupil/anna-k` to `main`

The teacher reviews the pull request, adds comments, and requests changes.
Corrections pushed to the same branch appear automatically in that pull request.
