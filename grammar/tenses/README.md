# Tenses

Group by **time**, then by simple / continuous / perfect.

| Folder | Typical level | Use for |
|---|---|---|
| `present-simple/` | A1–A2 | habits, facts, timetables |
| `present-continuous/` | A1–A2 | now, temporary, arrangements |
| `present-perfect/` | A2–B1 | experience, unfinished time, result |
| `past-simple/` | A1–A2 | finished events |
| `past-continuous/` | A2 | background, interrupted actions |
| `past-perfect/` | B1 | earlier past |
| `future-forms/` | A2–B1 | will / going to / present continuous |

Inside each folder, add a `README.md` plus exercises. Example starter: [`present-perfect/README.md`](present-perfect/README.md).
