# Conditionals

| Folder | Form | Meaning |
|---|---|---|
| `zero-and-first/` | If + present, present / will | facts, real future |
| `second-and-third/` | If + past, would / If + past perfect, would have | hypothetical now, hypothetical past |
| `mixed-and-wish/` | mixed conditionals, I wish / if only | regret and present result |

Useful with discussion lessons (including FIRE: “If I saved 40% of my salary…”).
