# Grammar

Reference notes, tables, and short drills for **one grammar point**. A full class still lives under `lessons/`.

Split grammar the way a teacher looks it up: **form family first**, then the specific structure.

```
grammar/
  tenses/                      time and aspect
    present-simple/
    present-continuous/
    present-perfect/
    past-simple/
    past-continuous/
    past-perfect/
    future-forms/
  conditionals/                if / unless / I wish
    zero-and-first/
    second-and-third/
    mixed-and-wish/
  modals/                      can, must, should, might…
  articles-and-determiners/    a / the / some / any / much
  prepositions/                time, place, dependent prepositions
  verb-patterns/               gerund vs infinitive, used to, have to
  clauses/                     relative, reported speech, passive
```

## What to put in a grammar folder

Example for `tenses/present-perfect/`:

- `README.md` — when to teach it, common mistakes, link to related lessons
- `form.md` — structure and examples
- `exercises.html` or `exercises.md` — gap-fill, choose the form, personalisation
- `answers.md` — if answers are not hidden in the HTML

Create a subfolder only when you have (or are about to write) material for that point. Empty folders are harder to maintain than a short README that lists “coming next”.
