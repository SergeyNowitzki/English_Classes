# Lessons

Complete classes the teacher can run as-is: aims, warm-up, input, practice, discussion, homework.

Do **not** split a finished lesson across grammar/vocabulary folders. Link those folders from the lesson README if students need extra drills.

## Layout

```
lessons/
  a2/
  b1/
  b1-b2/
    fire-retire-at-40/     ← one folder = one class
      README.md            ← 2-minute briefing for the teacher
      lesson.html          ← student page (open in a browser)
  b2/
  c1/
```

Create the level folder if it is missing. Copy [`templates/`](../templates/README.md) when starting a new class.
