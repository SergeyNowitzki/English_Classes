# Can You Retire at 40? (FIRE)

| | |
|---|---|
| Level | B1+ / B2 |
| Time | 75–90 minutes |
| Skills | reading, vocabulary, speaking, writing |
| Topic | money and lifestyle |

**Student page:** open [`lesson.html`](lesson.html) in a browser (double-click in Finder, or `open lesson.html` in Terminal).

Inspired by Harvey Jones, “Meet the people trying to save enough to retire by 40,” *The Guardian*, 18 August 2019. The HTML file is an original adapted lesson, not a copy of the article.

Suggested extra grammar later: conditionals for hypothetical plans (`If I saved more…`), comparatives, and discussion phrases (already in the lesson).
